# Final Render checklist

1. Push the whole folder to GitHub.
2. In Render, create/sync the Blueprint from `render.yaml`.
3. Confirm the Postgres database is created in Singapore (same region as the web service if you keep the default service region there).
4. Set `ADMIN_USERNAME` and `ADMIN_PASSWORD` when prompted.
5. `AUTH_SECRET` is generated by Render in the Blueprint.
6. Wait for Build to finish. Build must show both Puppeteer Chrome install and `Chrome verified:`.
7. Open `/ping` and confirm HTTP 200.
8. Open `/api/health` and confirm `database: postgres`.
9. Open `/admin.html` and verify the dashboard loads.
10. Test one user creation, balance add, certificate generation, and certificate search/download.
