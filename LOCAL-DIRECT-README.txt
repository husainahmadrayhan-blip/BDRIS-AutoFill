BDRIS AutoFill - LOCAL DIRECT FINAL

1. Extract this ZIP into a NEW folder.
2. Double-click RUN-SERVER.bat.
3. Open http://localhost:3000
4. Main app requires NO username, NO password, NO test account, NO access link, and NO balance account.
5. Do NOT open index.html by double-click.
6. If an old BDRIS server is running, RUN-SERVER.bat stops the process using port 3000 first.
7. Admin panel is separate: http://localhost:3000/admin.html
8. This build disables browser caching for the main app/API so an old login page is not reused.
