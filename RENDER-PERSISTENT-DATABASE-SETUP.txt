RENDER + NEON PERSISTENT STORAGE

1. Create/attach a Neon PostgreSQL database.
2. Add DATABASE_URL (pooled Neon connection string), AUTH_SECRET (stable random secret), ADMIN_USERNAME, and a strong ADMIN_PASSWORD in Render Environment.
3. Set LOCAL_DIRECT_MODE=false.
4. Build command: npm install
5. Start command: npm start
6. Verify logs contain [Neon] Connected and the admin panel shows Neon connected.

On startup, the app creates fil_users, fil_admin_settings, fil_balance_history, fil_payments, and fil_income. Existing local users are migrated only if the Neon fil_users table is empty. If DATABASE_URL is configured but connection/schema setup fails, the server refuses to start rather than silently switching to local JSON.

Balance history and admin-approved recharge balances persist in Neon. This does not configure an external payment gateway. PDF/image assets are filesystem files and require a persistent disk or object storage on hosts with ephemeral filesystems.
