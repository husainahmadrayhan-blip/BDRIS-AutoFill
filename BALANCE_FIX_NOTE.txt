BALANCE ZERO FIX
- Valid encrypted access payload is now preferred during login, so a server restart with an old/empty local users.json does not overwrite the latest balance.
- Fresh balance auth payload is stored in sessionStorage and localStorage keyed by access token.
- Existing auth/access/balance API behavior is preserved.
- Render Free filesystem is still ephemeral; this is a stateless access-payload recovery fix, not a replacement for an external database/persistent disk.
